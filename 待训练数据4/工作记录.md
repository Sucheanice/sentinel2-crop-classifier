# 作物分类 — 工作记录 (2026-07-22 ~ 2026-07-27)

## 项目概述
利用 Sentinel-2 多时相影像（2025年4期物候关键期），对遂宁市**安居区**和**射洪市**标注地块进行光谱特征提取，训练 XGBoost 分类模型，生成作物分布图（玉米/水稻/高粱）。

## 已知问题

### 1. 射洪市命中率仅 2.8% — 空间覆盖不足
- **原因**: 射洪市在 UTM 48N 的北界为 3,447,267m，但下载的 S2 tile **48RWU** 北界仅到 3,400,020m
- 射洪市约 88% 的地块在 tile **48RWV**（下一个100km方格向北），只有南端 ~6.6km 在 48RWU 内
- 已有 48RWV tile 数据可供下载（同4日期，云量: 2.5% / 58.4% / 32.9% / 0.3%）

### 2. 下载脚本代理问题
- `download_sentinel_v2.py` 中的 `set HTTPS_PROXY=...` 在 Python 子进程中不生效
- 需要在 Python 代码中显式设置 `os.environ['HTTPS_PROXY']`

### 3. 模型泛化能力
- 射洪模型基于 871 样本（39水稻/15高粱），样本量严重不足
- 需下载 48RWV tile 后重新训练

### ESA WorldCover 农田掩膜 (2026-07-28)
- **问题**: 原始 crop_map_shehong.tif 将全部像素分类为作物(水稻/玉米/高粱)，建筑物/水体/林地也被判为水稻
- **方案**: 用 ESA WorldCover 2021 全球 10m 土地覆盖 (class 40 = 农田) 过滤非农田像素
- **数据**: ESA_WorldCover_10m_2021_v200_N30E105_Map.tif (108 MB, EPSG:4326, 36000x36000 像素)
- **处理**: rasterio reproject → UTM 48N (EPSG:32648)，重采样至 3842x5407 @10m，最近邻插值
- **掩膜前** crop_map 有 20,766,577 有效像素（0=背景不计入），WorldCover 判定 5,435,528 像素为农田(26.2%)
- 射洪区实际土地利用覆盖: 林地 66.9%, 农田 26.2%, 建筑 3.1%, 水体 2.0%, 草地 1.1%, 裸地 0.8%
- **掩膜后** 有效农田像素: 5,432,764（水稻 717,054 + 玉米 4,696,991 + 高粱 18,719）
- 非农田区 ~1530 万像素清零（不再错误分类为水稻/玉米）
- **局限**: WorldCover 2021 年数据，2025 年可能存在土地利用变化
- 输出: `待训练数据6_shehong\crop_map_shehong_masked.tif` (uint8, nodata=0, LZW 压缩)
- 脚本: `mask_cropland.py` (下载 WorldCover + warp + 掩膜，总耗时 ~192s)
- **注**: 安居区也已完成掩膜+DOM重采样（见下方）
