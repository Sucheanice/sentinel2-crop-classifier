# 工作记录 · 耕地 shp 跨影像拼接

> 记录日期：2026-09-17
> 目的：村落横跨两幅影像时会得到多个 `*_farmland.shp`，需要拼成一份完整、无重叠、无半块的耕地地块层。
> 本次把拼接方法从"以某一幅为主"改成"按区域归属谁更完整就用谁"，并固化为可独立运行的脚本。

---

## 一、问题

前序环节按影像出耕地 shp。影像很大、村落跨在影像接缝上时，同一片耕地会落在两幅影像里，得到两份 shp：

```
成果数据/0917 前序环节数据/26/farmland/
├── 绵阳1_farmland.shp    17046 块    X 35466015.5~35476302.0   Y 3508782.8~3522138.0
├── 绵阳2_farmland.shp     8775 块    X 35466377.2~35477550.8   Y 3515477.4~3523636.4
└── 绵阳_farmland_merged.shp  ← 拼接成果
```

坐标系均为 EPSG:4523，字段一致：`id / area_px / area_m2 / score / class / code`。

两幅在空间上重叠：重叠范围 x 9924.8 m、y 6660.6 m；既南北错开、又东西错开（"双交"）。

**关键现象**：影像被自身边界切断时，边界附近的地块只切出一半。所以不能简单"以绵阳1为主"或"按 midline 一刀切"——
初版按"以绵阳1北边界切"处理后，接缝处留下了半块（如合并结果的 id 8 / 15 / 78 / 98，都是绵阳1被切断的一半，
对应绵阳2 里才是完整地块）。

## 二、实测：每幅影像"在哪儿被切断"

沿 y 方向逐 100 m 带统计"一方有、另一方没有"的耕地面积（足迹差）：

| y 区间 | 绵阳1 独有 | 绵阳2 独有 | 判断 |
|---|---|---|---|
| 3515477 ~ 3516600 | **17 ~ 24 ha/带** | 0 ~ 1.8 ha | 绵阳2 被其南边界切断 → 此处该用绵阳1 |
| 3516600 ~ 3520350 | 2 ~ 8 ha | 2 ~ 10 ha | 两幅基本对等（都完整） |
| 3520350 ~ 3522138 | 2 ~ 4 ha | **22 ~ 33 ha/带** | 绵阳1 被其北边界切断 → 此处该用绵阳2 |

沿 x 方向同样有较弱但真实的边界效应：绵阳2 靠其西边界（x≈35466377）偏少、绵阳1 靠其东边界（x≈35476302）偏少。

**结论**：每幅影像在其自身边界内侧约 1~2 km 的带内分割不完整；重叠区应把每个位置判给"离自己影像边界更远、
即更靠内部、分割更完整"的那一幅。

## 三、归属判据

设影像 i 的外包框为 `[x0,y0,x1,y1]`，位置 p：

```
d_i(p) = min( p.x-x0, x1-p.x,   仅当该方向两幅存在"交接"（一幅更靠小值侧、另一幅更靠大值侧）时才计入
              p.y-y0, y1-p.y )  ——方向对齐的那一轴不参与（两幅边界相同，无谁更完整之分）
归属 = argmax_i d_i(p)          逐地块按质心判定
```

该判据不需要人工选方向，天然覆盖三种叠置情形：

| 情形 | 分界表现 |
|---|---|
| 南北单交（上下两幅、x 范围相同） | 一条水平中线 |
| 东西单交（左右两幅、y 范围相同） | 一条垂直中线 |
| 双交（两个方向都错开） | 阶梯折线，四个方向的边界都被考虑 |

## 四、拼合方式（贪心 + 裁剪）

按「归属侧优先 → score 高优先 → 面积大优先」逐块并入，每块先裁掉与已并入内容重叠的部分，再判断是否保留：

- 裁完剩余既占比很小、又绝对面积很小（< `KEEP_RATIO` 且 < `SLIVER_MAX`）→ 判为重复地块的"壳"，丢弃
- 非归属侧的裁剪补块剩余 < `MIN_FILL_AREA` → 判为细碎条带，丢弃
- 裁剪产生的碎片 < `MIN_PIECE_AREA` → 丢弃；未裁剪的源地块原样保留

这样得到的结果同时满足：**无重叠、无半块（跨分界线的地块由归属侧整块保留）、归属侧漏掉的部分由对侧补齐**。
注意：只"整块丢弃"会漏掉大片地块（实测最大一处 314 亩被整块删掉），必须改为裁剪补入。

参数：`KEEP_RATIO=0.3`、`SLIVER_MAX=5000 m²`、`MIN_FILL_AREA=300 m²`、`MIN_PIECE_AREA=100 m²`。

面积按几何重算：`area_m2 = 几何面积`，`area_px = area_m2 / 0.64`（实测源数据 area_m2/area_px 中位为 0.6403）。

## 六、代码与用法

脚本：`成果代码/merge_farmland_shp.py`（仅依赖 geopandas / shapely / numpy，可独立运行）

```bash
cd "E:\工作相关\2026年\0624 待测试数据\成果代码"

# 最简：给目录，自动识别其中恰好 2 个 *_farmland.shp
python merge_farmland_shp.py --dir "E:\...\26\farmland" --out "E:\...\26\农田_farmland.shp"

# 显式指定两幅
python merge_farmland_shp.py --a 绵阳1_farmland.shp --b 绵阳2_farmland.shp --out merged.shp

# 外包框不能代表影像范围时（或想固定接缝位置）→ 手动指定方向与分界比例
python merge_farmland_shp.py --dir ... --out ... --mode y --split-ratio 0.5

# 输出附加 src 字段，便于核对接缝（默认不加）
python merge_farmland_shp.py --dir ... --out ... --add-src
```

脚本自带的能力（无人值守可跑）：

- 自动判定叠置方式（南北单交 / 东西单交 / 双交）、自动算归属，无需人工选方向
- 输入校验：文件不存在、要素为空、两幅坐标系不一致都会明确报错
- 两幅无重叠时按并列合并并提示
- 输出文件被 GIS 占用时自动改写为 `*_new.shp`，不会中途失败
- 每次运行打印：叠置方式、重叠范围、归属示意、归属侧/补块/丢弃数、来源分布、残留重叠、面积合计

## 七、顺带发现的前序数据质量问题（非拼接引入）

在 `26/farmland` 两份源 shp 里发现（本次已按几何重算面积，其余保持原样）：

1. **`area_m2` 属性与几何面积不符**：绵阳1 2069 块、绵阳2 1201 块（合计 3270 块），集中在绵阳1北部带。
   例：绵阳1 第 7 行（id8）几何 52432 m²，属性却写 8470 m²。
2. **近零面积退化地块**：绵阳1 11 块、绵阳2 4 块（4 顶点、坐标几乎重合）。
3. **同一 shp 内部互相压叠**：绵阳1 9 对（涉及 17 块）、绵阳2 5 对（涉及 10 块）。

第 1 条建议反馈前序环节核对面积字段的生成口径。

## 八、遗留

- 拼接后仍有 879 亩（占重叠带 2.8%）未被覆盖，其中 200.7 亩是成形缺口（最大单处 16.93 亩），
  来源于对侧候选被"重复/过碎"规则过滤。若下游不允许任何缺口，可放开 `MIN_FILL_AREA` / `KEEP_RATIO` 重跑。
- 本脚本按"恰好两幅"设计；若后续出现三幅及以上叠置，需要扩展为多幅两两判定。
