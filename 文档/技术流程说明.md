# Sentinel-2 多时相作物分类技术流程

## 项目概述

基于 Sentinel-2 多时相遥感影像与地块级标注数据，利用 XGBoost 机器学习模型实现遂宁市安居区及射洪市的作物类型分类（玉米、水稻、高粱等）。核心思路：利用作物在不同生长阶段的独特光谱特征（植被指数时间序列），通过监督学习区分作物类型。

**研究区域**：四川省遂宁市  
- 安居区（105.09-105.71E, 30.18-30.47N，约 15,273 个标注地块）  
- 射洪市（105.26-105.66E, 30.67-31.16N，约 31,075 个标注地块）

**Sentinel-2 瓦片**：MGRS 48RWU（单瓦片覆盖全部研究区域）

---

## 1. 数据获取

### 1.1 标注数据（SHP）

来源：农业部门提供的2026年度地块级农作物种植调查数据。

| 字段 | 说明 |
|------|------|
| `ZWMC` | 作物名称（玉米、水稻、高粱等），作为分类标签 |
| `BZ` | 备注信息（套种大豆、制种、未出苗等附加说明） |
| `geometry` | 地块多边形（EPSG:4326） |

安居区标注作物：玉米（7,679块）、水稻（7,594块），为二分类任务。  
射洪市标注作物：玉米（22,264块）、水稻（6,748块）、高粱（1,678块）、及其他少量类别。

### 1.2 Sentinel-2 多光谱影像

数据来源：**Earth Search STAC API**（Element84 托管，AWS 公开存档，无需认证）。  
产品类型：Sentinel-2 Level-2A（大气校正后地表反射率）。  
使用波段：B02（蓝）、B03（绿）、B04（红）、B08（近红外），均为 10m 空间分辨率。

### 1.3 影像时相选择策略

影像时相选择是本项目的关键技术决策。根据遂宁地区玉米和水稻的物候期，选取覆盖关键生长阶段差异的影像。

#### 遂宁主要作物物候期

| 月份 | 玉米（春玉米） | 水稻（一季中稻） | 遥感区分价值 |
|------|---------------|-----------------|-------------|
| 4月 | 出苗 | 育秧中 | 中 |
| 5月 | 拔节期 | 移栽/返青（水田） | ★★★ |
| 6月 | 抽穗-开花 | 分蘖-拔节 | ★★★ |
| 7月 | 灌浆-乳熟 | 抽穗-开花 | ★★ |
| 8月 | 成熟收获 | 灌浆-乳熟 | ★★★ |

#### 2025年实际下载影像（48RWU瓦片）

| 日期 | 卫星 | 云量 | 物候意义 | 选择原因 |
|------|------|------|---------|---------|
| 2025-05-20 | S2B | 1.45% | 玉米拔节 vs 水稻返青 | 低云量，5月区分窗口最佳 |
| 2025-06-26 | S2A | 20.78% | 玉米抽穗 vs 水稻分蘖 | 覆盖玉米生殖生长关键期 |
| 2025-07-16 | S2A | 11.64% | 玉米灌浆 vs 水稻抽穗 | 低云量，作物光谱差异显著 |
| 2025-08-03 | S2C | 0.00% | 玉米收获 vs 水稻灌浆 | 无云，收获前后区分度最大 |

**选择原则**：
1. 每个关键物候窗口选取1景，覆盖完整生长季
2. 优先选择云覆盖率 < 30% 的影像
3. 四川盆地7-8月多云南，Agent早季（5月/8月无云）和云量相对较低的窗口
4. 4-5月区分窗口最理想但因存档原因替代为5月20日

**下载脚本**：`download_sentinel_v2.py`，使用 `pystac-client` 搜索 Earth Search 目录，自动下载指定瓦片和日期的4个10m波段COG（Cloud-Optimized GeoTIFF）文件。

## 2. 数据预处理

### 2.1 影像裁剪

下载的 Sentinel-2 影像为完整 100km × 100km 瓦片（约 10,980 × 10,980 像素），远超研究区域范围。为减少处理内存和时间，按 SHP 地块范围的并集外扩 100m 缓冲区进行裁剪。

### 2.2 坐标系转换

- SHP 数据：EPSG:4326（WGS84 地理坐标）
- Sentinel-2 影像：UTM Zone 48N（EPSG:32648）
- 使用 `pyproj.Transformer` 进行坐标转换

### 2.3 标签清洗

对 `BZ`（备注）字段进行正则清洗，合并"玉米套种大豆""玉米（套种大豆）"等变体为统一标注。射洪市保留玉米、水稻、高粱三类主要作物，其余低样本类别（白芷233、大豆105、李子47）归为"其他"。

---

## 3. 特征提取

### 3.1 像素级均值提取

对每个 SHP 地块多边形：
1. 在 Sentinel-2 影像上生成掩膜（`rasterio.features.rasterize`）
2. 提取掩膜内所有像素的 B02/B03/B04/B08 波段值
3. 计算该地块内各波段的**均值**作为特征

### 3.2 植被指数计算

对每个时相，在原始4波段基础上计算以下指数：

| 指数 | 公式 | 物理意义 |
|------|------|---------|
| NDVI | (NIR - Red) / (NIR + Red) | 植被绿度/生物量 |
| EVI | 2.5 × (NIR - Red) / (NIR + 6×Red - 7.5×Blue + 1) | 改进型植被指数，抗大气干扰 |
| NDWI | (Green - NIR) / (Green + NIR) | 水体/水分含量，区分水田 |
| SAVI | 1.5 × (NIR - Red) / (NIR + Red + 0.5) | 土壤调节植被指数，适合低覆盖 |

**特征维度**：4个时相 × (4个原始波段 + 4个植被指数) = **32个原始特征**

### 3.3 特征选择

使用 Random Forest（n_estimators=100, max_depth=8）计算特征重要性，选取 Top 30 重要特征，减少噪声和过拟合。

---

## 4. 模型训练

### 4.1 分类器：XGBoost

| 参数 | 值 | 说明 |
|------|-----|------|
| n_estimators | 100 | 决策树数量 |
| max_depth | 3 | 最大树深（防止过拟合） |
| learning_rate | 0.1 | 学习率 |
| subsample | 0.8 | 每棵树随机采样比例 |
| colsample_bytree | 0.8 | 每棵树随机特征比例 |
| reg_alpha | 0.5 | L1 正则化 |
| reg_lambda | 1.0 | L2 正则化 |
| objective | multi:softmax | 多分类目标函数 |

**正则化策略**：通过 `max_depth=3`（浅树）、`subsample=0.8`（行采样）、`colsample_bytree=0.8`（列采样）、L1+L2 双正则化，四重机制防止小样本情况下的过拟合。

### 4.2 交叉验证

- 方法：Stratified K-Fold（分层 K 折），保持各类别比例
- 折数：min(3, 最小类别样本数)
- 指标：Accuracy + Weighted F1

### 4.3 安居区 vs 射洪市

**分别训练两个独立模型**：
- 安居区：玉米 vs 水稻（二分类，15,273 个样本）
- 射洪市：玉米 vs 水稻 vs 高粱 vs 其他（多分类，31,075 个样本）

分开训练的原因：两个区域作物种植结构不同（安居区为纯玉米/水稻二元结构，射洪市有多样化作物），区域间土壤和气候条件也有差异。

---

## 5. 全图预测

1. 加载 4 个时相的全部 10m 波段到内存
2. 逐像素构建特征向量并计算植被指数
3. 选取与训练阶段相同的 Top 30 特征
4. XGBoost 逐像素预测类别
5. 输出单波段 Int16 分类栅格（nodata = -1）
6. 使用 LZW 压缩写入 GeoTIFF

## 7. 后续加强方向

### 7.1 数据层面
- **增加 Sentinel-1 SAR 数据**：四川盆地夏季多云，S1 的雷达数据不受云雨影响，可补充光学数据盲区。S1+S2 融合在文献中可提升 1-5% 分类精度
- **扩展小春作物**：当前仅覆盖大春（玉米、水稻），若获得油菜、小麦等小春作物标注，可扩展为双季分类
- **多年数据**：增加 2024 年同区域影像，增强模型年际泛化能力

### 7.2 模型层面
- **深度学习方法**：尝试 TempCNN、InceptionTime 等时序深度学习模型，文献中 F1 可达 93-99%
- **半监督/自监督学习**：利用大量无标注像素辅助训练，缓解标注数据不足的问题
- **迁移学习**：安居区训练 → 射洪市微调，评估模型跨区域泛化能力

### 7.3 特征层面
- **物候特征**：通过 Harmonic 拟合 NDVI 时间序列，提取物候参数（峰值时间、幅度等）
- **纹理特征**：利用 GLCM 等提取地块内部纹理信息，区分光谱相似作物
- **地形特征**：引入 DEM 高程/坡度/坡向，作物分布与地形高度相关

### 7.4 应用层面
- **与 1m DOM 结合**：将 10m S2 分类结果作为先验，辅助 1m 航片 DOM 的精细作物识别
- **年度更新**：每年基于新标注+新影像增量训练，建立时序作物分类产品
- **产量估算**：结合 NDVI 时序曲线与气象数据，估算作物产量

## 8. 前进村大春预测管线 (2026-08-10)

### 8.1 任务背景

江油前进村大春作物识别（水稻 vs 玉米），全程不依赖现成矢量数据。核心挑战：
- 没有 GDB 地块矢量可用（项目实际情况）
- 从 DOM 影像 + S2 影像自动完成耕地提取、地块分割、作物分类
- 四川细碎耕地，S2 10m 分辨率是硬瓶颈

### 8.2 数据

| 数据 | 来源 | 说明 |
|------|------|------|
| DOM (0.5m) | 前进村航片 | CGCS2000 GK35, RGB三波段, ~5km×5km |
| S2 影像 (10m) | Planetary Computer | 4 期: 05-20/06-26/07-16/08-03, 10波段 |
| 大春 v3 模型 | 遂宁五区训练 (93.6% Acc) | zonal-mean 输入, 水稻/玉米二分类 |
| 数字底图 | 前进村人工标注 (1826个多边形) | 仅用于训练 DOM RF 耕地掩膜, 不用于预测 |

### 8.3 技术路线 (最终: 路线 D)

```
DOM 0.5m 影像
    ↓
RF 耕地掩膜 (数字底图训练, 85.7% CV) → 0.5m 耕地/非耕地图
    ↓
ndimage.label 连通域 (3,242 个独立耕地块)
    ↓
降采样到 2m, 连通域内部 SLIC 分割
    ↓
ExG 植被比过滤 (< 0.15 丢弃)
    ↓
1,007 个地块 SHP (DOM CRS, CGCS2000 GK35)
    ↓
投影到 S2 CRS (UTM 48N), 负缓冲 -5m
    ↓
窗口裁剪 S2 波段, rasterize 地块 → zonal mean 提取
    ↓
v3 模型预测 (4期×10波段 + 植被指数 + 时序统计 + 物候)
    ↓
NDVI 二次校验: max_ndvi < 0.30 → 覆盖模型判定 → 非植被
    ↓
SHP 输出 (综合判定: 水稻/玉米/不确定/非植被)
```

### 8.4 与其他路线对比

| 路线 | 地块来源 | 关键改进 | 结果 | 评价 |
|------|---------|---------|------|------|
| A (GDB) | 人工矢量 | — | 玉米 45%, 水稻 44% | 不可用 (无 GDB) |
| B (WorldCover) | 10m 全球产品 | ExG+NDVI 过滤 | 玉米 58%, 不确定 31% | 10m 掩膜太粗 |
| C (Pixel模型) | 10m 栅格 | DOM 掩膜 + pixel模型 | 矢量化全是碎三角 | 失败 (栅格不适合直接转SHP) |
| **D (DOM分割+v3)** | **0.5m DOM** | **DOM掩膜+SLIC+NDVI双校验** | **玉米 62%, 不确定 15%, 非植被 49%** | **推荐** |

### 8.5 关键设计决策

**NDVI 二次校验优先级**:
```
模型预测 (统计猜测) < NDVI硬证据 (物理事实)
```
即使模型判为玉米/水稻, 若四期最大 NDVI < 0.30 (7月作物不可能这么低), 最终标为非植被。

**reproject 跨带转换优化**:
- DOM CRS: CGCS2000 GK35 (3度带, 中央经线 105°)
- S2 CRS: WGS84 UTM 48N (6度带, 中央经线 105°)
- 全图 reproject 120M 点挂死 → `transform_bounds` 先算重叠窗口 (0.2%) → 只在 250K 点做 pyproj 转换

**10m 分辨率瓶颈**:
S2 10m → DOM 0.5m 的映射是 1:400。一个 S2 像素覆盖 400 个 DOM 子像素。因此作物分类必须在 10m 做, 但地块边界必须在 0.5m 做。路线 D 正确分离了这两个环节。

#### 8.5.2 NDVI 阈值调节逻辑

NDVI 校验是整个管线中唯一的"手动旋钮"——不涉及重训模型, 直接通过数值阈值控制判别条件。

**NDVI 值的物理含义 (大春 5-8 月)**:

```
NDVI < 0.20  ── 建筑屋顶、水泥路面、水体 (几乎不可能有植被)
0.20 - 0.30  ── 稀疏草地、刚出苗 (<2周)、地块边缘混入道路像素
0.30 - 0.50  ── 低覆盖作物 (刚返青期、病虫害)、小地块边缘效应
0.50 - 0.70  ── 正常生长中作物 (拔节/分蘖期)
> 0.70       ── 茂盛期作物 (抽穗/灌浆期, NDVI 峰值)
```

> 注: 大春作物 5 月下旬已返青, 6-8 月处于旺盛生长阶段, 健康作物的 NDVI 极少低于 0.50。

**阈值对比 (前进村 1,007 地块实测)**:

| 阈值 | 被拦掉 | 保留 | 效果 |
|------|--------|------|------|
| 0.20 (宽松) | ~200 块 | ~800 块 | 只拦明显的建筑/道路, 低覆盖作物留得多但噪声也多 |
| **0.30 (当前)** | **497 块 (49%)** | **510 块** | 平衡点, 拦掉大部分非植被但不过度 |
| 0.40 (严格) | ~700 块 | ~300 块 | 宁可错杀不可放过, 不确定率降低但可能漏掉真正的低覆盖作物 |
| 0.50 (极严) | ~850 块 | ~150 块 | 几乎只留高置信作物, 适合出图给领导看 |

**调节指南**:

| 场景 | 建议阈值 | 原因 |
|------|---------|------|
| 初次探索 | 0.20 | 多看多判, 不急着下结论 |
| 日常使用 | **0.30** | 平衡 precision 和 recall |
| 出正式成果 | 0.40 | 宁可地块少但要准, 不确定的标为"待核实" |
| 验证模型 | 0.20 (或不启用) | 让模型尽可能多地判, 对比真值找 bias |

**参数位置**: `predict_qianjincun_v3_dom.py` 第 25 行 `NDVI_THRESH = 0.30`

**在 QGIS 中交互探索**: 加载 `qianjincun_prediction_dachun_v3_dom.shp` 后, 按 `ndvi_max` 字段做分级设色或属性过滤即可实时查看不同阈值下的分类结果, 无需重跑脚本。

**NDVI 校验的判据来源**: 取四期影像中该地块的 **最大 NDVI** (而非均值)。因为均值会被早期低 NDVI 拉低, 而最大值代表该地块在整个生长季里"最好的植被状态"。如果这个最大值都不到 0.30, 那这块地确实不是植被。
