# 1. 一句话概览

我们手上有 **7 套特征库**（水果 3 套：柑橘 / 蜜柚 / 桃；作物 4 套：水稻 / 玉米 / 小麦 / 油菜），
全部按同一口径建成：**540 维原始旬特征 → 98 维物候指纹**。
原始样本 211.4 MB，指纹库 57 KB，随时可用 pandas 直接读取，暂不需要数据库。

# 4. 口径：540 维和 98 维分别是什么

## 4.1 540 维原始特征

`Sentinel-2 SR`（`COPERNICUS/S2_SR_HARMONIZED`）+ `SCL` 云掩膜（3/8/9/10/11）→ **逐旬中位合成**
（每月上/中/下旬，全年 36 旬）× **15 个植被/水分指数** = **540 维**。

| 指数 | 主要反映 | 进指纹 |
|---|---|---|
| NDVI | 总体绿度 | 是 |
| SAVI | 稀疏植被绿度（抗土壤背景） | 是 |
| RVI | 近红外 / 红 | 是 |
| NDWI | 叶片 / 水体含水 | 是 |
| MNDWI | 改进水体（SWIR） | 是 |
| LSWI / NDII | 冠层含水量（两式相同） | 是 |
| NDRE | 红边归一化（叶绿素、早期胁迫） | 是 |
| NDI45 | 红边 705 / 665 | 是 |
| CVI | 叶绿素指数 | 是 |
| TCARI | 叶绿素吸收积分（抗土壤） | 是 |
| IRECI | 红边拐点 | 是 |
| MTCI | 红边位置（物候转折最灵敏） | 是 |
| GCVI | 绿波段叶绿素 | 是 |
| EVI | 高生物量 | 否（云残留噪声大） |

## 4.2 98 维指纹

14 个指数（不含 EVI）× 7 个物候指标 = 98 维：

| 指标 | 定义 |
|---|---|
| 冬 / 春 / 夏 / 秋 | 该季三个月 9 旬的均值（冬=12/1/2，春=3/4/5，夏=6/7/8，秋=9/10/11） |
| 振幅 | `mean(7、8 月) − mean(12、1、2 月)` |
| 冬稳定 | `std(12 月 3 旬)` |
| 成熟期 | `mean(10、11 月)` |

指纹文件每行一个指标，列是 `P10 / P25 / P50 / P75 / P90 / mean / std / MAD / N`，
**这 9 个统计量就是"特征库"本体** —— 打分时用典型区间与离散度衡量待判地块有多像。

# 5. "点数"是什么意思

图例里的「8,144 点 / 9,000 点」= **参与建库的 Sentinel-2 像元个数**（10 m 分辨率，1 点 = 1 个像元），
不是地块数、也不是亩数。

- 水果：在用户于 Google Earth 画的每个多边形内部随机撒点，按面积给配额（每 100 m² 一个点，单个面 60~9,000 点封顶）
- 作物：先按区县分层随机抽 300 块地，再把选中地块的并集内部随机撒 3,000 点（点落在哪块地就归哪一类）

点数决定指纹统计量的稳定性：3,000 点以上，P10~P90 与 MAD 已相当稳定；
小麦 / 油菜的 3,019 / 3,010 点属于可用下限。

# 6. 库的体积构成

| 组成 | 体积 | 说明 |
|---|---|---|
| 7 个原始样本 CSV（540 列） | **211.4 MB** | 水果 96.0 MB + 作物 115.4 MB |
| 7 个指纹 CSV（98 行 × 10 列） | **57 KB** | 真正的"库"，可直接人读 |
| 9 张可分性对比 CSV | 约 40 KB | 逐维 Cohen's d + 区间重叠度 |

「113 MB」是**作物库单独的大小**（115.4 MB，含水稻/玉米/小麦/油菜四套原始样本）；
算上水果库，全部原始样本是 **211.4 MB**。

# 8. 跨区验证：绵阳 4 镇抽检

**目的**：水稻/玉米库的样本来自遂宁、泸州、雅安，没有绵阳。用绵阳交付件里「同事前序数据」
的作物标签当参照（`CROP_BZMC` = 水稻 / 玉米），检验库能否直接迁到绵阳。

**方法**：每镇分层随机抽 300 块水稻 + 300 块玉米 → 提取 540 维 → 与两套库分别比对 →
得分高者判为该作物。同时用两种口径：

- 口径 A（区间打分）：P10~P90 区间内 1 分，区间外高斯衰减
- 口径 B（对称距离）：`mean(|x − 库中位| / 库MAD)`，取距离小者（不受库宽窄影响）

| 镇 | 样本 | 一致率 A | 一致率 B | 水稻查准 | 玉米查准 | 高置信样本 | 高置信一致率 |
|---|---|---|---|---|---|---|---|
| 黎雅镇（梓潼） | 600 | 0.680 | 0.630 | 0.523 | 0.737 | 93 | 0.731 |
| 水晶镇（平武） | 600 | 0.653 | 0.638 | 0.643 | 0.633 | 136 | 0.713 |
| 新安镇（江油） | 600 | 0.637 | 0.632 | 0.367 | 0.897 | 163 | 0.834 |
| 富驿镇（盐亭） | 600 | 0.563 | 0.553 | 0.433 | 0.673 | 107 | 0.645 |
| **合并** | **2,400** | **0.633** | **0.613** | **0.492** | **0.735** | **499** | **0.741** |

**诊断**：逐维比较"水稻 − 玉米"的效应量（Cohen's d）

| 指标 | 库内（遂宁等） | 绵阳 4 镇 |
|---|---|---|
| 平均 \|d\| | 0.41 | 0.25 |
| 与库同号的维度占比 | — | 84% |
| 富驿镇平均 \|d\| | — | 0.17（几乎无区分度） |

**结论**：

1. **方向是对的**：84% 的维度在绵阳与库内同号，说明物候规律没有反转，库不是"用错地方"。
2. **强度衰减明显**：平均效应量 0.41 → 0.25，绵阳地形破碎、地块小、混合像元多，类间差异被稀释。
3. **直接当分类器不够用**：总体一致率 63%，水稻召回仅 49%；但**高置信子集（499 块，20.8%）达 74%**。
4. **建议用法**：库只作"筛查 / 第二意见"，高置信子集可直接用，其余交人工或补绵阳样本后重标定。
   补 300~500 块/类的绵阳地块（水稻、玉米各一）即可在本地重算指纹，预计能把一致率拉到 80% 以上。
5. 富驿镇（盐亭）几乎无区分度，优先怀疑该镇标签质量或地块破碎度，不建议在此镇使用作物库判定。

# 9. 已知短板与下一步

| 短板 | 影响 | 建议 |
|---|---|---|
| 水稻/玉米样本不含绵阳 | 跨区迁移衰减，一致率 63% | 补绵阳 300~500 块/类样本后重建 |
| 小麦/油菜仅遂宁 3 区 | 地理代表性弱 | 若要在绵阳判小春，需补川北样本 |
| 蜜柚 1/2/6/10 月、桃 2/11 月缺观测 | 常绿/物候判据在缺月只能靠邻月 | 换用多年合成或降云掩膜阈值 |
| 2 月小麦/油菜全部缺云 | 冬季特征只靠 1、12 月 | 同上 |
| 苹果 / 猕猴桃 / 枇杷尚未建库 | 需求已提出 | 等 Google Earth 手绘范围后按同一命令建库 |

**是否入库**：暂不需要。指纹库仅 57 KB，流程是"读一次全量计算"，没有并发查询；
入库反而增加表与文件不同步的风险。出现多批次追溯、多人看板或库版本并存需求时再上，
首选 SQLite 单文件，其次 PostGIS。
