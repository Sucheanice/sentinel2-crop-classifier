## 一、完成内容

### 1.1 新建 segment_parcels.py

从 0.5m-1m DOM 影像自动提取地块边界，输出 SHP（WGS84），用于新区域无现成地块 SHP 的场景。

**核心流程**：
```
DOM 影像 → 降采样 → 农田掩膜 → SLIC 超像素分割 → 植被/农田过滤 → 矢量化 → SHP
```

**实测结果（安居区 1m DOM）**：
- 输入：4145×3154 像素，1m 分辨率
- WorldCover 掩膜下输出 3177 个地块，面积中位数 2227 m²
- 蓬南镇 7.46cm 影像（降采样到 0.5m）输出 790 个地块，面积中位数 2055 m²

### 1.2 三种掩膜方案对比

在安居区 1m DOM 上对比测试：

| 掩膜方法 | 农田/植被覆盖率 | 保留区域数 | 过滤比例 | 评价 |
|---------|-------------|----------|---------|------|
| 无掩膜 | - | 5624 | 0% | 切割建筑、山林、水体 |
| ExG 超绿指数 | 95.8% | 5586 | 0.7% | **几乎无效**（夏季全是绿的） |
| **WorldCover 10m** | **46.9%** | **3177** | **43.5%** | **有效**（区分农田 vs 树林） |

**结论**：ExG 只能区分"绿色 vs 非绿色"，无法区分农田与树林/灌丛/草地。WorldCover 基于 ESA 全球土地覆盖产品，能区分农田（class 40）与其他地类，效果显著更好。

### 1.3 坐标系修复

DOM 影像的 `.prj` 普遍写成非标准 `LOCAL_CS` 格式，导致 QGIS 报"没有可用转换"错误。

**修复方式**：
- 自动检测 CGCS2000 3-degree Gauss-Kruger 的两种变体（带/不带 zone 前缀）
- 用 WKT 字符串直接构建 CRS，绕开本机 PostgreSQL 18 旧版 proj.db 冲突
- 输出 SHP 统一转 WGS84 (EPSG:4326)，QGIS 可直接加载

### 1.4 参数化设计

```bash
python segment_parcels.py \
  --dom <DOM.tif> \
  --output <parcels.shp> \
  --target-res 0.5 \           # 处理分辨率
  --compactness 20 \           # SLIC 紧致度
  --min-area 200 \             # 最小地块面积
  --mask-method worldcover \   # 掩膜：worldcover / exg / none
  --veg-threshold 0.3          # 农田像素占比阈值
```

## 二、遗留问题

| 问题 | 说明 | 严重程度 |
|------|------|---------|
| SLIC 边界不够精细 | 传统方法局限，丘陵小地块边界贴合度有限 | 中等（人工可修正） |
| WorldCover 10m 分辨率 | 掩膜边界是 10m，对 0.5m DOM 来说粗糙 | 低（过滤效果已满足需求） |
| 分割块为超像素非真实地块 | SLIC 按光谱+空间聚类，不等同于真实地块边界 | 中等（需人工二次编辑） |
