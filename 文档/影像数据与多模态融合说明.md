# 影像数据与多模态融合说明（通俗版）

> 面向非遥感专业背景，用大白话讲清楚三件事：瓦片命名、哨兵1号/2号联动、GF高分影像融合。

---

## 一、Sentinel-2 瓦片命名（48RTR、48RWV 是什么意思）

### 1.1 为什么要切格子

地球太大，卫星影像不可能一整张发给你，所以全球被切成一个一个的"格子"来存储和分发。Sentinel 用的格子叫 **MGRS 瓦片**，每个约 **110 公里 × 110 公里**。你下载的 `48RTR`、`48RWV`、`48SVA` 就是这些格子的"门牌号"。

### 1.2 一个门牌号由 5 位组成

拿 `48RWV` 举例，拆成四段看：

| 位置 | 字符 | 含义 | 通俗解释 |
|------|------|------|---------|
| 第 1-2 位 | `48` | 经度带（UTM zone） | 按经度把地球竖着切成 60 条，每条 6° 宽，编号 1-60。四川盆地（东经 102°-108°）正好是第 **48** 条 |
| 第 3 位 | `R` | 纬度带（band） | 按纬度把地球横着切成 20 条，每条 8° 高，用字母 C 到 X 表示。**R = 北纬 24°-32°**（四川盆地南部），**S = 北纬 32°-40°**（川北山区） |
| 第 4 位 | `W` | 100km 列 | 上面两条交叉出来的大方块，再切成 100km 的小格，这一位表示**东西方向**的位置 |
| 第 5 位 | `V` | 100km 行 | 这一位表示**南北方向**的位置 |

### 1.3 实战例子（对照你的项目）

| 瓦片 | 拆解 | 大概位置 |
|------|------|---------|
| `48RTR` | 48带 + R带 + 列T + 行R | 四川东南部（古蔺/叙永一带） |
| `48RWV` | 48带 + R带 + 列W + 行V | 遂宁一带 |
| `48SVA` | 48带 + **S**带 + 列V + 行A | 江油/平武一带（比 R 带更靠北） |
| `48SWA` | 48带 + S带 + 列W + 行A | 江油东部/梓潼北部 |

### 1.4 一看就懂的记忆法

把它想成**围棋棋盘**：

1. 先按经度划 60 条竖线（数字 1-60）；
2. 再按纬度划 20 条横线（字母 C-X）；
3. 每个交叉出的方块，再切成 100km × 100km 的小格；
4. 每个小格用两个字母命名：**前一个字母 = 东西位置（列），后一个字母 = 南北位置（行）**。

所以相邻的地块，门牌号也相邻：`48RWV` 的东边邻居是 `48RWW` 方向、南边邻居是 `48RWS` 方向。看到门牌号，就知道这块地在地球上的哪个方格。

## 二、哨兵1号（雷达）和哨兵2号（光学）怎么联动

### 2.1 两个卫星的本质区别

| | 哨兵2号（S2） | 哨兵1号（S1） |
|---|---|---|
| 类型 | **光学卫星**（像照相机） | **雷达卫星**（像雷达/声呐） |
| 拍什么 | 可见光 + 红外，共 13 个波段 | 微波回波（VV、VH 两种极化） |
| 成什么样 | 真彩色照片，能看出颜色和植被 | 灰度图，反映地物**粗糙度、含水量、结构** |
| 致命弱点 | **怕云**——云一挡就啥也看不见 | 几乎不怕云、雨，能昼夜成像 |
| 分辨率 | 10m（可见光/近红外） | 约 10-20m |

一句话：**S2 看得清"颜色"，S1 看得清"形状质地"，且 S1 全天候不怕云。**

### 2.2 为什么要联动

四川盆地夏季云特别多——刚才 48SWA 那个瓦片，6 月整月云量都超过 90%，光学影像基本瞎了。这时 S1 就能"补盲区"：云挡不住雷达。

### 2.3 怎么联动（多模态融合）

把 S1 和 S2 的特征**拼成一张大表**，一起喂给模型：

- **S2 提供光谱特征**：NDVI、NDWI 等植被指数，反映"长得绿不绿、有没有水"；
- **S1 提供雷达特征**：VV/VH 后向散射，反映"是水面还是旱地、地面糙不糙"。

拿水稻 vs 玉米举例：

| 特征 | 水稻 | 玉米 |
|------|------|------|
| S2 的 NDWI（水分） | 高（插秧期田里灌水） | 低（旱地） |
| S1 的 VV 回波 | 弱（水面光滑，微波像照镜子反射走） | 强（旱地粗糙，微波散射回来） |
| S2 的 NDVI 时序 | 有自己的节奏 | 节奏不同 |

两类特征互补，模型判断更准。文献上 S1+S2 融合通常比单用 S2 提升 1-5 个百分点的精度。

### 2.4 联动前要处理什么

S1 也要做预处理，大致是：轨道校正 → 热噪声去除 → 辐射定标 → 地形校正 → 转成 dB 值。然后**和 S2 重采样到同一分辨率、对齐到同一坐标系**，才能逐像素拼接。项目里之前果园用过的 `iw-vh.tiff`、`iw-vv.tiff` 就是 S1 的 VH/VV 极化数据。

## 三、GF-2 / GF-6 高分影像怎么融合进来

### 3.1 GF 是什么、好在哪

| | GF-2（高分二号） | GF-6（高分六号） |
|---|---|---|
| 分辨率 | 全色 0.8m / 多光谱 3.2m | 全色 2m / 多光谱 8m |
| 波段 | 4 个（蓝绿红近红外） | 8 个（含红边，专门面向农业） |
| 对比 S2 | 分辨率高得多（S2 是 10m） | 同样远高于 S2 |

**GF 的最大价值是"看得清"**：S2 一个 10m 像素，在 GF-2 里能拆成 100 多个 0.8m 像素。细碎地块的边界、单块田的纹理，S2 看不清，GF 能看清。

但 GF 也有短板：重访周期长、且你往往只有一期或几期，**做不了 S2 那种 5/6/7/8 月的完整时序**。

### 3.2 融合的价值（分工）

- **GF 定边界**：用 0.8-8m 高清影像，把地块边界、细碎耕地的轮廓勾准；
- **S2 定类别**：用 10m 多时相光谱，判断这块地是水稻还是玉米；
- **S1 补盲区**：云多的地方用雷达兜底。

三者各司其职，合起来 = 高清边界 + 物候过程 + 全天候。

### 3.3 需要先调整什么（你最关心的问题）

你问"角度？坐标？还是别的？"——答案是**主要调坐标和辐射，角度一般不用动**。按重要性排序：

| 顺序 | 要调整的 | 为什么 | 通俗说法 |
|------|---------|--------|---------|
| 1 | **坐标系统一** | GF 是国产卫星，通常用 **CGCS2000** 坐标系；S2 用 **WGS84/UTM**。两者不统一，同一块地在两张图里位置会对不上 | "把两张地图的底图换成同一套经纬度" |
| 2 | **几何配准** | 坐标统一后，两张图可能还有几米~几十米的微小偏移，要"配准"让它们精确重叠 | "把两张照片对齐到像素级" |
| 3 | **辐射/大气校正** | GF 拿到的是 L1 级原始数据（DN 值），要转成**地表反射率**，才能和 S2 的 L2A（已经是反射率）对比 | "统一亮度标准，去掉大气雾霾影响" |
| 4 | **重采样到统一分辨率** | GF 0.8m 和 S2 10m 差太多，融合前要拉到同一分辨率 | "把照片缩放到同一个像素大小" |
| 5 | **波段对齐** | GF-2 只有 4 波段，S2 有 10+ 波段，融合时取公共波段（蓝绿红近红外） | "只比大家都有颜色的那几个通道" |

> **关于"角度"**：卫星观测角度（天顶角/方位角）主要影响 BRDF（反射随角度变化）。正规的 L2 级产品通常已经记录或校正了角度，**对多模态融合来说不是主要调整项**。真正卡住融合的是上面的 1-4。

### 3.4 务实建议（按你手头数据量）

| 你手头的 GF 数据 | 建议用法 |
|----------------|---------|
| **只有一期** | 当"高清参考层"：用它勾精细地块边界，或人工抽查 S2 分类对不对。别指望一期 GF 做时序分类 |
| **有 2-3 期** | 可以额外建 GF 的小时序特征，但期数少、价值有限；更值钱的是 GF+S2 的波段/纹理融合 |
| **多期覆盖生长季** | 才能谈 GF 独立做时序分类（但这种情况少见，成本高） |

**一句话总结**：你现在最省事的做法是——**S2（多时相）负责分类，GF（高清）负责定边界和验证，S1（雷达）负责补云盲区**。GF 融入前，先过"坐标统一 → 配准 → 辐射校正 → 重采样"这四关，就能和 S2 一起用了。
