## 六、整体恢复流程（重启后执行）

### 步骤 1: 确认 GPU 可用
```bash
nvidia-smi
```
如出现 `Driver/library version mismatch` 错误，执行 `reboot` 再次重启。

### 步骤 2: 验证 Docker 已启动
```bash
systemctl status docker
docker ps
```
Docker 和 compose 项目应自动启动（restart policy）。如未启动，按上表逐项目恢复。

### 步骤 3: 启动 Xinference
```bash
source /root/anaconda3/etc/profile.d/conda.sh
conda activate xin
nohup xinference-local --host 0.0.0.0 --port 9997 > /tmp/xinference.log 2>&1 &

# 等 30 秒后验证
sleep 30
xinference list
curl http://localhost:9997/v1/models
```

### 步骤 4: 检查所有端口
```bash
ss -tlnp | grep -E '80|443|3306|5432|6379|9997|8001|8002|8072|8090|8091|8092|8093|8765|8899|5003'
```

### 步骤 5: 抽查关键服务
```bash
# Dify
curl -s http://localhost:80 | head -5

# mappingwisdom_v2 后端
curl -s http://localhost:8001/health

# 三区三线
curl -s http://localhost:8002/health

# GIF
curl -s http://localhost:8899/health

# Xinference
curl -s http://localhost:9997/v1/models
```
