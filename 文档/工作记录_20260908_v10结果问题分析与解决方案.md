## 二、关键调查结论

### 2.1 影像波段：有第 4 波段（确认为 NIR），当前代码未使用

- 影像：4 波段、uint16（12bit，值域约 0-4095）、0.8m、EPSG:4523。
- 波段 1/2/3 互相关极高（0.94~0.97）→ RGB；波段 4 与 RGB 去相关（0.05~0.23）→ NIR。
- 证据：用 band4(NIR) 与 band3(红) 计算 NDVI，林地与其它 polygon 分离明显：

| 指标 | 林地（用户标注 24 个） | 其它（约 7040 个） |
|---|---|---|
| NDVI 均值 | 0.099（p50=0.097） | -0.066（p50=-0.104） |
| 亮度（原始 uint16） | 745 | 924 |

- 结论：band4 是 NIR，林地 NDVI 显著高于耕地（该时相耕地多为收割/休耕），可用于林地过滤。
- 当前代码只用前 3 波段（RGB），NIR 被丢弃。

### 2.2 暗色过滤存在量纲 bug

- `_filter_dark_polygons` 与 SLIC 亮度门 `dark_p10_threshold=69`、`slic_min_brightness=70`，注释声明单位为 0-255，但读取的是原始 uint16（值约 700~900），未归一化。
- 后果：阈值 69/70 远小于实际值 700~900，亮度门从不触发，"深色林地过滤"实际失效。

### 2.3 shp 结构：全部 Polygon，顶点过多

- 7064 个要素，几何类型全部为 Polygon（v10 写盘已把 MultiPolygon 展开）。
- 顶点数：<=20 有 5734；>300 有 25；最大 938 顶点，均值 19.7。
- "点过多"实际是边界顶点过多（SAM 像素级 mask 转矢量后未充分简化）。

### 2.4 v10 vs v9 差异

- 唯一实质差异：v10 新增 `_merge_touching_and_fill()` + `_fill_holes_geom()`（相接合并 + 补洞）。
- 合并补洞使漏检减少，但也把相邻林地碎块过度合并/填洞，误检增加。

## 三、逐问题解决方案

### 问题 1：显存/速度
- 显存 7.5GB 正常（SAM3 推理计算密集非显存密集）。
- 慢的根源：438 窗口双尺度重叠推理。
- 方案：加 GPU（vllm 已停，可用 6 卡）+ 跳过无效窗口 + batch。

### 问题 3：林地误识别
- 方案：① 修亮度门量纲；② 新增 NDVI 林地过滤（band4=NIR）；③ 负样本栅格化后用于重训或训练二分类器。

### 问题 4：边界凹进/折角
- 根因：重叠裁剪用布尔差 `difference`，割出对方边界。
- 方案：改分数优先权 + 最终 buffer 平滑填凹口。

### 问题 5：边界锯齿
- 根因：`mask_smooth_sigma=1.0`、`simplify_tolerance=1.0` 太弱。
- 方案：sigma→2.0、simplify→2.5，加 Chaikin 圆角。

### 问题 6：`class: detected`
- 硬编码占位符，改为 `farmland`。

### 问题 7：顶点过多
- 方案：顶点上限约束 + 更强 Douglas-Peucker 简化。

## 七、第二轮反馈与修正（2026-09-08）

### 7.1 用户反馈

1. **问题1（边界）**：原 v10 地块边比 v10_fix 好很多，调过头了。id 2918 原版规整、fix 版像 6/7 边形；几乎所有地块都如此，且 fix 版较影像有内收。应**沿用原版描边**，减少点的正确做法是「共线点合并」（两点在直线/近似直线上就合并成直线）。
2. **问题2（暗色过滤）**：加负样本后林地少了，但**部分耕地被误删**：id 2181、511、512、2337、2047、2175、509、2176、2045、2173、224、1581。问如何调参，或引入波段判断。

### 7.2 根因定位

- **内收**：`final_smooth_buffer=1.5` 做了 `buffer(1.5).buffer(-1.5)`（外扩再内缩），净效果整体内收。
- **6/7 边形**：`final_smooth_chaikin=1` 的 Chaikin 圆角把每个顶点切成 1/4、3/4 分割点，把直线边/尖角都磨圆，地块被磨成多边形。
- **误删耕地**：暗色阈值 40 太激进，暗色耕地（p10 27~39）被误判为林地。

### 7.3 诊断数据（原 shp 实测）

**原版顶点数分布**：min=5 p25=10 p50=13 p75=18 p90=28 p99=149 max=938；总数 7064。
顶点 >100 仅 115 个、>200 仅 48 个 → **原版绝大多数地块顶点其实不多，只有少数极端多边形需要简化**。

**亮度 p10（归一化 0-255）**：
- 24 个林地：22 个 <12，2 个偏亮（191=34.4、845=25.4）。
- 11 个误删耕地：27.1~38.6，全部 >27。

**NDVI（band4=近红外，band3=红）**：
- 林地 NDVI 均值 0.044~0.170；耕地 0.054~0.145。
- **两者高度重叠，NDVI 单独无法区分林地和暗色耕地**（本影像林地偏稀疏/幼龄，NDVI 不高）。

### 7.4 修正方案

**问题1（边界回退）**：
- 删除 `buffer` 回缩（去内收）、删除 `Chaikin` 圆角（去多边形化）。
- `_final_smooth_polygon` 改为**纯 Douglas-Peucker 共线点合并**。
- 参数回退：`simplify_tolerance` 2.5→1.0、`mask_smooth_sigma` 2.0→1.0。
- `max_vertices=200`：**仅对超过 200 顶点的 48 个极端多边形**渐进加大 simplify 共线合并，其余保持原版描边不动。

**问题2（暗色过滤修正）**：
- 阈值 40→**25**：0 误删这 11 个耕地（p10 都 >27），仍删 22/24 林地（p10 <25）。
- **NDVI 单独不可行**（数据证明重叠），不引入 NDVI 主过滤；更彻底区分需纹理特征或训练分类器（长期）。

## 八、长期优化方向：林地 vs 耕地 的精确区分

### 8.1 当前方案的边界（已实现，约 85 分）

- 暗色亮度阈值 `p10<25` 能删 400 个暗色林地、且不误删已确认的 12 个耕地。
- 但**纯亮度**仍存在两类残差：
  1. **偏亮林地漏删**：如林地 id 191（p10=34.4）、id 845（p10=25.4），亮度不低、被保留为误检；
  2. **更暗耕地可能误删**：本次 12 个耕地的 p10 都在 27 以上，但不排除其它更暗的湿土/阴影耕地 p10<25 被误删。

### 8.2 为什么 band4 指数单独不行（已实测，含波段修正）

> ⚠️ 修正：早期判断「band4=NIR」存疑。2026-09-09 复核波段值域：band1/2/3 均值约 857/850/839，band4 均值 834、max 仅 1381（远低于 band3 的 2149）。若为 NIR，植被上反射应更强、值应更高；实际 band4 整体偏暗，更像 SWIR/其它波段。**本影像大概率没有标准 NIR 波段**。

因此 8.2 中「NDVI」实为 band4/band3 的比值指数（非标准 NDVI），实测：

- 林地该指数均值 0.044~0.170；
- 耕地该指数均值 0.054~0.145。

**两者高度重叠**，无论叫不叫 NDVI，都无法作为主过滤特征。已完成的暗色亮度过滤（p10<25）只依赖亮度、不依赖该波段，结论不受此修正影响。

### 8.3 纹理特征思路（推荐，无监督）

林地与耕地的本质差异在**纹理**而非单一光谱：

- **林地**：树冠间隙产生明暗阴影，纹理粗糙、高频成分多 → GLCM 同质性低、对比度高；
- **耕地**：田面/作物相对均匀，纹理平滑 → GLCM 同质性高、对比度低。

可落地做法：对每个 polygon 在影像内计算灰度共生矩阵（GLCM）的**同质性/对比度**，或 Gabor 响应、局部方差、边缘密度等纹理指标，与亮度 p10 组合成「亮度 + 纹理」二维决策（例如：暗 AND 纹理粗糙 → 林地删除；暗 AND 纹理平滑 → 保留）。这无需额外标注数据。

### 8.4 训练分类器思路（需扩充负样本）

用已标注的林地（24 个）+ 耕地样本，栅格化后提取像素级特征（RGB + NDVI + 纹理），训练随机森林/轻量二分类器做后过滤。要能泛化，需扩充负样本到：

- **多村**（不能只学宝珠村）；
- **多时相**（不同季节林地光谱差异大）；
- **多类型非耕地**（水域、建筑、道路、裸地、阴影）。

### 8.5 结论

短期用亮度阈值 25 已可接受（85 分）；要再往上提，优先做**纹理特征组合**（无需标注、可立即实施），训练分类器作为需要扩充数据后的长期手段。

| 红蓝差>30 + 面积>2000m² | 22.4% | 46.7% |

**最好也就召回 ~36%、精确 ~29%**，不可靠。

**根因**：大棚光谱签名是「偏红（band3>band1，98%）+ 纹理平滑 + 面积大」，但本影像存在**大量裸土/红土田块**，与大栅光谱几乎一致（同样偏红、平滑、规则），单靠 4 波段光谱 + 简单纹理 + 形状无法区分。

**结论**：纯规则/光谱/纹理方法不可行，大棚识别需引入**深度学习**（微调 SAM 加大棚类，或训练分类器）。

## 十、水体识别（2026-09-09）

### 10.1 背景与方法

用户要求判断 SAM3 能否直接识别水体。结论：**原始 `sam3.pt` 权重 + `--prompt water` 可直接识别水体**（farmland 微调 checkpoint 会灾难性遗忘 water，故必须用原始权重）。

推理命令（服务器，6 卡）：

```bash
nohup python geo_infer_v10_multigpu.py \
  --input /data3/sam3_project/test_data/tif/baozhucun.tif \
  --output /data3/sam3_project/test_data/result_baozhucun_water/baozhucun_water \
  --prompt water \
  --gpus 0,2,3,4,5,6 \
  --checkpoint /data4/sam3_project/sam3_train/Code/sam3-main/model/sam3.pt \
  --geometric-refine 0 --confidence-threshold 0.3 \
  --dark-p10-threshold 0 --ndvi-threshold 0 \
  --simplify-tolerance 1.0 --mask-smooth-sigma 1.0 \
  --max-vertices 200 \
  --min-area-m2 50 --merge-touching 1 --merge-fill-hole-m2 0.0 \
  --stretch 0 --slic-points 0
```

结果：6 卡 123.29s，导出 782 个 polygon，总面积 1562.46 亩。

### 10.4 结论

1. **面状水体效果好**：水库（81%）、较大坑塘召回不错，精确率 80.7%，原始 `sam3.pt + water` 对成片开阔水面可靠。
2. **短板在窄/线状水体**：沟渠几乎全漏（1.1%）、河流只召回 25.6%，根因是滑动窗口 + 50㎡ 最小面积 + 窄线状几何的固有缺陷。
3. **误检可接受**：主要是旱地/水田的暗色光谱混淆，与大棚/林地的混淆同类，属正常噪声。

**决定**：水体识别暂不调整，维持当前版本。
