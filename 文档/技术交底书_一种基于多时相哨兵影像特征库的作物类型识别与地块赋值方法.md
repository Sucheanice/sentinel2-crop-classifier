# 发明专利 专利申请技术交底书

| 项目 | 内容 |
|---|---|
| 发明名称 | 一种基于多时相哨兵影像特征库的作物类型识别与地块赋值方法 |

---

## 一、所属技术领域

本发明属于遥感（RS）与地理信息技术领域，涉及遥感影像的作物类型智能识别，具体涉及一种利用多时相哨兵（Sentinel）系列影像的多光谱波段与植被指数构建作物特征库，并对待赋值地块逐块判定作物类型、完成属性赋值的方法。

本发明所称"待赋值地块"，指前序环节（影像分割或矢量整理）输出、已具备地块边界但缺少作物类型属性的地块矢量，作为本发明的输入数据。

---

## 二、背景技术

作物类型识别是农情监测、种植结构调查与面积统计的基础环节。基于多时相卫星影像的自动识别已成为主流技术路线，但现有方法仍存在以下不足：

1. **识别结果依赖单一分类器，缺乏可复用的特征基准。** 现有方案通常用一批样本训练一个分类模型，模型输出即为结论。模型参数不可读、判别依据不可查，一旦更换年份、区域或作物组合，只能重新采样、重新训练；已积累的样本与特征无法沉淀为可复用的知识资产。

2. **忽略作物物候的空间分异，跨区迁移精度下降。** 同一作物在不同海拔、纬度、品种下物候期可相差十余天至一个月。现有方案多以单一样本集训练、全区域套用，把物候差异误当作类别差异，山区尤为明显。

3. **逐旬特征缺失时缺乏补提机制。** 西南地区云雨频繁，某一旬可能整旬无有效观测。现有方案在特征缺失时直接留空或整块剔除，造成大批地块无结论。

4. **地块尺度与影像像元尺度不匹配。** 作物识别通常在 10 m 级影像上完成，而实际地块远小于该尺度（实测地块面积中位数可低至 0.72 亩，约 480 ㎡，仅 4~5 个像元）。对不足一个像元的小地块，逐块分类在物理上不成立，现有方案未作区分，直接逐块套用分类结果。

5. **只有结论、没有可信度。** 现有方案输出作物类别即止，不给出该结论的判别通道、置信程度与特征缺失情况，人工复核无从下手。

---

## 三、本发明所要解决的技术问题

针对上述缺陷，本发明要解决的技术问题是：如何将多时相影像特征沉淀为可复用、可核查的作物特征库，并以此为基础对待赋值地块完成稳定、可解释、无遗漏的作物类型赋值。

具体包括：

1. **解决特征不可复用的问题**：提供一种作物特征库的构建方法，按"作物类别 × 物候分区 × 旬 × 特征维"组织，以稳健统计量形式存储，使样本与特征成为可跨年、跨区复用的资产。
2. **解决物候空间分异的问题**：提供物候分区的划分与库的匹配规则，使同一作物按不同物候区分别建库、分别匹配，避免把物候漂移误判为类别差异。
3. **解决逐旬特征缺失的问题**：提供"逐旬优先 + 宽窗兜底"的特征补提机制，在整旬无有效观测时自动改用跨旬宽窗合成。
4. **解决尺度失配的问题**：提供地块级识别单元的双轨判定，对不足一个像元或有效像元不足的地块改为聚合统计，既不丢块也不硬算。
5. **解决结论不可核查的问题**：提供分类器与特征库两条判别通道，二者一致性决定置信档，并输出判别通道、概率与缺失标记。

## 四、技术方案简介

本发明提出一种基于多时相哨兵影像特征库的作物类型识别与地块赋值方法，技术特征如下：

**特征 1：待赋值地块数据的核验与规范化**
接收前序环节输出的地块矢量，逐项核验类别字段、坐标系等价性、几何有效性与行政归属；剔除空几何、自交与面积过小的碎片；计算每块面积 A、内切圆半径 r_in 及在识别影像上的覆盖像元数 N = A / g²（g 为影像地面分辨率）；建立地块与影像分幅、行政单元的索引关系。

**特征 2：逐旬合成与宽窗兜底**
以旬（上旬、中旬、下旬）为时间单元，对哨兵影像按云掩膜（SCL）筛选有效观测并逐旬合成；当某旬有效像元数低于阈值时，自动扩展为跨旬的 20 天宽窗重新合成；仍不足则记为缺失并打标记，不参与该旬特征的统计。

**特征 3：多光谱与植被指数特征体系**
以地块多边形内缩缓冲后的有效像元为统计对象，按有效像元数加权，提取五组特征：原始多光谱波段反射率、植被指数（NDVI、EVI、NDRE、NDWI、MNDWI、LSWI）、时序统计量（均值、极值、振幅）、物候关键日期（返青期、成熟期）、首尾差；基础口径共 145 维，叠加 SAR 后向散射与纹理后扩展至 380 维。

**特征 4：作物特征库的构建（核心）**
以已有作物类别标注的地块为样本，经样本净化、物候分区后，按"作物类别 × 物候分区 × 旬 × 特征维"的层级结构，计算并存储稳健统计量（中位数、MAD、P10、P90、样本数）；以 Cohen's d 与区间重叠率做可分性筛选，仅保留判别力达到阈值的特征维；支持按新增样本增量合并与版本管理。

**特征 5：双通道作物判别**
通道 A 为梯度提升树分类器，输出各类别概率；通道 B 为特征库匹配，逐地块计算到各作物库的归一化稳健偏离度 d_c = mean(|x − median_c| / MAD_c)，取最小者为匹配类别；两通道结论一致且概率达标记为高置信，不一致则降档并进入人工复核队列。

**特征 6：尺度失配双轨判定与逐块赋值**
按特征 1 的覆盖像元数将地块判为独立识别单元或聚合单元（后者并入所属较大地块或村域聚合单元统一统计后回填）；对仍无有效观测的地块按"最高概率类 + 低置信标记"回退；最终将作物类别、概率、置信档、判别通道、缺失标记写回地块属性，输出赋值后的地块矢量。

## 五、与以往技术相比的有益效果

1. **特征可复用、结论可核查。** 特征库以稳健统计量形式沉淀，同一套库可跨年、跨区调用，新的样本只需增量合并；任何地块的结论都可回溯到具体特征维与库中位值，便于复核与追责，避免了"黑箱模型只能重训"的困境。
2. **跨区迁移精度稳定。** 按物候分区建库后，同一作物在不同海拔带分别匹配，避免把物候漂移误判为类别差异；实测以 23 个县、90,301 个标注地块建库并迁移至另一地市，水稻与玉米分类精度达 93.58%，小春油菜召回率 84.5%。
3. **云雨条件下不丢块。** 逐旬优先、20 天宽窗兜底的补提机制，使整旬无有效观测时不至于整批地块失分；配合双轨判定与回退，实测 22 个任务区 392,876 个地块全部完成赋值，而原口径下有明确结论的仅 52.7%。
4. **解决小地块不可识别的问题。** 实测某村 6,675 个分割地块中，30.7% 在 10 m 影像上不足 3 个像元，面积小于 300 ㎡ 的地块中 87% 属此情形、19.7% 完全无覆盖；双轨判定将这部分地块聚合统计，使其全部获得结论。
5. **结论带可信度，复核有抓手。** 双通道一致性与概率共同决定置信档，输出判别通道与缺失标记，人工复核可直接按低置信队列优先处理，避免全量翻查。
6. **算力要求低、可业务化。** 识别阶段仅需梯度提升树与常规栅格统计，软件均可开源获取，已在跨 5 个影像分幅、22 个乡镇的范围内完成规模化生产。

## 七、具体详细的实施方式

### 步骤 S1：待赋值地块核验与规范化

**S1.1 输入**

前序环节输出的地块矢量，字段至少包含地块标识、类别（如 `farmland`）、面积与几何；本实施例中影像地面分辨率 0.8 m，坐标系为 CGCS2000 3° 带高斯—克吕格（EPSG:4523）。

**S1.2 核验项**

1. 类别字段是否为预期类别，非目标类别（如水系、建筑）剔除或单独存放；
2. 坐标系是否与识别影像等价，不等价则重投影；
3. 几何有效性：`buffer(0)` 修复自交，剔除空几何；
4. 行政归属：按行政界线做空间包含判定，无归属者按最大重叠面积归属；
5. 覆盖范围：统计落入识别影像有效范围的面积占比，低于阈值者标记为覆盖不足。

**S1.3 几何量算**

对每块计算面积 A、周长 P、形状指数 SI = P / (2√(πA))、内切圆半径 r_in，以及

```
N = A / g²
```

其中 g 取 10 m（哨兵多光谱影像地面分辨率）。

---

### 步骤 S2：逐旬合成与宽窗兜底

**S2.1 逐旬合成**

将作物生长季按每月上、中、下旬划分为若干时间单元。对每个时间单元：

1. 检索该旬内全部可用影像；
2. 用 SCL 分类层生成云掩膜，剔除云、云影、雪；
3. 逐像元取该旬内有效观测的中位数（或云量最低单景），得到逐旬合成影像；
4. 记录每旬的有效观测数。

**S2.2 宽窗兜底**

当某旬地块内有效像元数低于阈值 N₀（本实施例取 3）时：

```
扩展窗口 = 该旬向前、向后各延伸至累计 20 天
```

在扩展窗口内重新筛选有效观测并合成；扩展后仍不足的，该旬特征记为缺失，置 `nodata` 并打 `miss` 标记，不以 0 或邻期均值填充（避免引入伪信号）。

**S2.3 合理性**

山区的整旬无有效观测是常态（本实施例中曾出现某旬两景全部被判为云、该旬覆盖率为零），逐旬优先保证了时间分辨率，宽窗兜底保证了可用性，二者构成"精度优先、可用兜底"的两级策略。

---

### 步骤 S3：多光谱与植被指数特征提取

**S3.1 统计掩膜**

对地块多边形做负向缓冲：

```
b = min(0.5 × g, 0.2 × r_in)
```

本实施例 g = 10 m，故 b 取 5 m 与 0.2·r_in 的较小值。仅像元中心落入缓冲后多边形的像元参与统计，以剔除田埂、道路、沟渠与阴影等边界混合像元。

**S3.2 五组特征**

| 组别 | 内容 |
|---|---|
| 第 1 组 原始波段 | 蓝、绿、红、近红外、红边 1/2/3、窄近红外、短波红外 1/2 的反射率 |
| 第 2 组 植被指数 | NDVI、EVI、NDRE、NDWI、MNDWI、LSWI |
| 第 3 组 时序统计 | 各指数在生长季内的均值、最大值、最小值、振幅 |
| 第 4 组 物候特征 | 返青期、抽穗期、成熟期等关键日期的像元级推算值 |
| 第 5 组 首尾差 | 生长季首末两期同一指数的差值，表征后期衰减速率 |

基础口径共 145 维。扩展口径叠加 Sentinel-1 VV/VH 后向散射（dB）及邻域纹理统计，共 380 维，用于云雨影响更重或类别更细的区域。

**S3.3 统计规则**

1. 先按云掩膜与 `nodata` 剔除，再统计；
2. 以有效像元数为权重做加权平均，而非简单平均；
3. 有效像元数不足时，沿 S1 的索引上溯至聚合单元重新统计（见 S6）。

---

### 步骤 S4：作物特征库的构建

**S4.1 样本来源与类别标注**

以具备作物类别标注的地块为样本，样本应覆盖目标作物的主要种植区。本实施例采用跨 23 个县的 90,301 个标注地块，类别含玉米 52,564、水稻 34,957、高粱 2,154 等。

**S4.2 样本净化**

按以下规则剔除不可靠样本：

1. 地块内有效像元数 < N₀；
2. 地块内 NDVI 标准差超过阈值（表明地块内作物混杂或含大量非植被）；
3. 生长季 NDVI 最大值低于阈值（表明本身不是正常生长作物）；
4. 与相邻类别地块存在大面积重叠的边界样本。

**S4.3 物候分区**

按海拔与纬度划分物候区（本实施例按海拔分为 ≤500 m、500~800 m、>800 m 三带），同一作物在不同物候区分别建库。分区的目的是把物候漂移从类别差异中剥离出来。

**S4.4 库的层级结构**

```
作物类别
 └ 物候区
    └ 旬（时间单元）
       └ 特征维（145 / 380）
          ├ 中位数 median
          ├ 稳健离散 MAD
          ├ P10 / P90
          └ 样本量 n
```

采用中位数与 MAD 而非均值与标准差，是为了抑制异常样本与云污染对库的污染。

**S4.5 可分性筛选**

对任意两类作物、任一特征维计算

```
Cohen's d = (median_1 − median_2) / s_pooled
区间重叠率 = 两库 P10~P90 区间的重叠长度 / 并集长度
```

保留 |d| ≥ 0.8 且区间重叠率 ≤ 0.2 的特征维作为判别维，其余维在通道 B 中降权或剔除。该步骤使"库"不仅可查，而且可评估。

**S4.6 库的更新**

新增样本按物候区与旬增量合并，重算稳健统计量并递增版本号；当某作物某物候区样本量低于阈值时，退回上一级（全省口径）库并标注来源。

---

### 步骤 S5：双通道作物判别

**S5.1 通道 A：分类器**

以梯度提升树（LightGBM）训练多分类模型，输入为 S3 的特征向量，输出各类别概率 p_k 与最大概率类。样本与特征库同源，保证两通道口径一致。

**S5.2 通道 B：特征库匹配**

对每个地块，按物候区选择对应库，逐维计算归一化稳健偏离：

```
d_c = mean_k( |x_k − median_{c,k}| / MAD_{c,k} )
```

取 d_c 最小的作物类别为匹配类别；同时记录该偏离度与次小偏离度之差，作为可分性裕度。

**S5.3 双通道融合与置信档**

| 情形 | 置信档 |
|---|---|
| 两通道结论一致且 p ≥ 0.80 且缺失旬数 ≤ 1 | 高 |
| 两通道结论一致，但 p 或缺失旬数不达标 | 中 |
| 两通道结论不一致 | 低（进入人工复核队列） |

输出字段：作物类别、概率 p、匹配偏离度 d、判别通道（A／B／一致）、缺失标记 `miss`。

---

### 步骤 S6：尺度失配双轨判定与逐块赋值

**S6.1 双轨判定**

```
若 (N < N₀) 或 (A < A₀) 或 (有效像元数 < N₀)  → 聚合单元
否则                                          → 独立识别单元
```

本实施例取 N₀ = 3、A₀ = 300 ㎡。聚合单元以所属较大地块（无则村域耕地聚合单元）的范围统一统计特征，判别结果回填至该单元下全部地块。

**S6.2 回退**

聚合后仍无有效观测的，取通道 A 的最高概率类强制判定，置信档标"低"并置 `conf_flag = 1`；生长季 NDVI 最大值低于阈值的，判为非作物并单列，不参与作物面积统计。

**S6.3 赋值回写**

将作物类别、概率、偏离度、置信档、判别通道、缺失标记、单元类型、来源影像编号写入地块属性，输出赋值后的地块矢量（含 shp 与 gpkg）。属性字段与地块一一对应，不另出附属表。

---

### 实施例 1：单村地块的尺度适配与赋值

对象为某村 0.8 m 分辨率 4 波段影像分割所得耕地地块 6,675 块，地块面积中位 0.72 亩。

按 S1 量算，全部地块中覆盖像元数 N < 3 的占 30.7%（2,048 块）；面积 < 300 ㎡ 的 1,664 块中，87% 属"过小"、19.7% 完全无覆盖。

按 S6 双轨判定，上述 2,048 块转入聚合单元；经 S2~S5 处理，6,675 块全部获得结论：玉米 5,490 块、水稻 454 块、非作物 731 块（其中无覆盖 367、不确定 330 按回退规则取最高概率类并标"低"，非植被 34 块单列为非作物）。

### 实施例 2：跨区建库与迁移识别

以 23 个县的 90,301 个标注地块按 S4 建库（玉米 52,564、水稻 34,957、高粱 2,154），样本净化后按海拔三带分区。迁移至另一地市 5 个区县推理，水稻与玉米二分类测试集精度 93.58%；小春口径下小麦与油菜二分类，油菜召回率 84.5%。

同一批样本在未分区建库时，山区样本与平坝样本混库，水稻在海拔 800 m 以上区域的漏判明显高于分区后，验证了 S4.3 分区的必要性。

### 实施例 3：22 个任务区规模化赋值

对象为 5 个县 22 个乡镇，跨 5 个影像分幅，影像为生长季逐旬哨兵多光谱数据。

- 待赋值地块 392,876 块，总面积 1,854,994 亩；
- 完成作物赋值 202,303 块（水稻 49,578、玉米 152,725）；
- 未采用宽窗兜底与回退时：云覆盖缺失 33.7%、不确定 5.0%、无覆盖 7.5%，有明确作物结论的仅 52.7%；
- 采用 S2 宽窗兜底与 S6 回退后，赋值结果无空白，低置信块与 `conf_flag = 1` 的块单独统计，进入人工复核队列。

## 附录 B：与在先技术的区别（《一种西南山地破碎化耕地农作物精细解译算法》）

| 维度 | 在先技术 | 本发明 |
|---|---|---|
| 核心产出 | 精细解译成果（矢量边界 + 类别） | 可复用的作物特征库 + 带置信度的地块赋值 |
| 分类方式 | 一次训练、一次分类 | 分类器与特征库双通道判别，互相校验 |
| 物候处理 | 未按物候区拆分 | 按物候区分别建库、分别匹配 |
| 特征缺失 | 未说明补提机制 | 逐旬优先 + 20 天宽窗兜底，缺失留标记不填充 |
| 尺度适配 | 像素分类结果按重叠关系填充分割地块 | 先做识别单元双轨判定，再对聚合单元统一统计回填 |
| 可信度 | 未输出 | 输出概率、偏离度、判别通道与三级置信档 |
| 可复用性 | 换区换年需重训 | 库可增量合并、版本管理，跨区调用 |
