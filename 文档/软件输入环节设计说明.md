# 软件输入环节设计说明

> **版本**：v1（讨论固化版）
> **日期**：2026-08-31
> **范围**：仅覆盖「输入环节」——如何敲定任务范围、接收地块数据、触发 GEE 识别。输出环节、模型调度、结果后处理不在本文档内。

---

## 一、背景与目标

把现有的「GEE 提取 + LightGBM 作物/用地识别」能力软件化，让非技术用户能自主完成：**选定范围 → 上传地块数据 → 得到带识别结果的交付表**。

当前核心能力（已验证）：

| 能力 | 数据源 | 粒度 | 精度 |
|------|--------|------|------|
| 大春作物识别（水稻/玉米） | Sentinel-2 多期 | 地块级 | 92~93% |
| 用地分类（水田/旱地/园地/林地/宅基地等） | 高分 RGB | 图斑级 | 四大类 83.4% |
| 像素级作物识别（兜底） | Sentinel-2 | 像素级 | 低于地块级 |

---

## 二、输入环节整体流程

```
① 选行政范围   省 → 市 → 县（三级下拉，本地内置边界）
② 选任务类型   大春作物 / 用地分类 / 地块边界类型
③ 上传地块边界  shp 或 含 WKT 列的 xlsx（主路径）；或仅圈范围（兜底）
④ 确认期数/年份  默认当年；大春自动用关键 3 旬
⑤ 提交运行     前置校验 → GEE 提取 → 模型分类 → 导出交付表
```

---

## 三、行政范围选择

- **形式**：省 → 市 → 县 三级下拉框，本地内置一套省市区县边界（离线可用）。
- **到县即可**：村/乡镇信息由地块数据自带的「村编码」提供，不额外下拉。
- **作用**：
  1. 限定 GEE 影像检索范围（`filterBounds`）；
  2. 结果命名与归属；
  3. 校验上传数据是否落在所选县内（防选错）。

---

## 四、任务类型选择

三种任务对应三种输出编码体系（见第九节）：

| 任务 | 输出内容 | 数据源/时相 | 成熟度 |
|------|----------|-------------|--------|
| 大春作物识别 | 水稻/玉米 | Sentinel-2，关键 3 旬（5月上+7月中+8月中） | ✅ 成熟 |
| 用地分类 | 农用地/其他水域/其他土地/建设用地 4 大类 18 小类 | 高分 RGB（DOM）单期 | ✅ 可用 |
| 农业生产分类 | 种植/养殖/林业地块 3 大类 13 小类 | 待定 | 🔶 初步 |

---

## 五、地块边界输入（两种模式）

### 5.1 模式 A：已有地块边界（主路径，覆盖 95% 场景）

**输入**：同事/甲方分好的地块边界 shp，或含「地块边界(WGS)」WKT 列的 xlsx。

**处理流程**：

```
读 shp/xlsx → 转 WGS84 → 筛选「耕地」地块 → GEE reduceRegions(zonal mean)
    → 模型分类 → 把作物编码写回每个地块 → 导出交付表
```

**工程要点**：

| 点 | 说明 |
|----|------|
| CRS | 对方可能是 CGCS2000 或其他投影，需先转 EPSG:4326（GEE 要求） |
| "耕地"筛选 | 只对标记为耕地的地块跑作物识别，其他地类跳过，避免误判 |
| 多村合并 | 多个村的地块 shp 可合并为一个大输入，一次跑完，再按「村编码」拆分赋值 |
| 批量 | 地块多时分批（现有脚本已验证 4.2 万块 / batch 3000） |

### 5.2 模式 B：无地块边界（兜底，可延后）

**输入**：只有村界/任务范围，同事还没分割好地块。

**处理流程**：

```
圈定范围 → 像素级作物识别 → 输出像素级作物图
    → 矢量化成「粗略地块 + 作物标签」（标注 10m 边界、待精细边界替换）
```

**明确 trade-off**：像素级精度低于地块级，矢量化边界受哨兵 10m 限制（田埂 0.5m 做不到）。此结果仅作**粗版**，等精细边界 shp 到位后套用重跑。

## 六、字段预留与透传规则

**核心原则：只依赖最少字段，其余原样透传，不做假设。**

软件输入必须/可选识别的字段：

| 字段 | 必要性 | 说明 |
|------|--------|------|
| 几何（geometry / 地块边界 WKT） | 必须 | 识别的最小空间单元 |
| 地块唯一编码 | 可选 | 若有则透传；无则按规则生成 |
| 村编码 / 村名称 | 可选 | 有则透传并用于结果归属；无则预留空列 |
| 是否耕地 / 地类标记 | 可选 | 有则用于筛选；无则默认全部处理 |
| 其他属性字段 | 透传 | 原样保留，不影响识别 |

**地块唯一编码生成规则**（无输入时）：`G + 村编码(12位) + 6位序号`，如 `G510781118205000001`。

## 七、智能纠错（前置校验清单）

| 校验项 | 检查内容 | 不通过时的处理 |
|--------|----------|----------------|
| 上传数据校验 | CRS 是否可转 4326、几何是否有效（自交/空几何）、必要字段是否齐、地块数是否合理 | 定位到具体行，给出修复建议 |
| 范围匹配 | 上传地块几何是否落在所选县内 | 提示"所选县与数据不符"，列出实际所属县 |
| GEE 认证/配额 | 认证是否有效、配额是否够 | 引导重新认证，或提示分批 |
| 影像云量/覆盖 | 目标区关键时相云量过高或有效像元不足 | 提前告警，建议调整年份/时相 |

> 注：影像云量预警、结果合理性检查属于运行中/运行后，但统一在此说明。

**可选智能增强**：若上传数据自带「村编码」，可自动解析出市县（村编码前 6 位为行政区划代码，如 `510781`=江油市），与用户手选的县做交叉验证。

## 八、GEE 调用流程（技术实现）

```
本地 geopandas 读 shp/xlsx
    → 简化几何（容差约 10m）
    → ee.FeatureCollection
    → Sentinel-2 S2_SR_HARMONIZED，按县/地块范围 filterBounds
    → 时相窗口 filterDate + SCL 云掩膜 + median 合成
    → reduceRegions(mean, scale=10, tileScale=4)
    → 输出每地块 zonal mean 特征 CSV
```

大春关键时相窗口（已由数据驱动验证）：

| 旬 | 日期窗口 |
|----|----------|
| 5月上 | 05-01 ~ 05-10 |
| 7月中 | 07-11 ~ 07-20 |
| 8月中 | 08-11 ~ 08-20 |

## 九、交付数据格式（9 列）

软件输出的交付表固定为 9 列：

| # | 列名 | 说明 |
|---|------|------|
| 1 | 序号 | 从 1 递增 |
| 2 | 村编码 | 12 位，如 `510781118205` |
| 3 | 村名称 | 如「前进村委会」 |
| 4 | 期数（时间） | 调查/识别日期，如 `2026-08-20` |
| 5 | 五级标的编码 | 分类结果编码 |
| 6 | 五级标的名称 | 分类结果名称 |
| 7 | 地块唯一编码 | 如 `G510781118205000001` |
| 8 | 地块边界（WGS） | WKT 文本 `MULTIPOLYGON(((...)))` |
| 9 | 实际面积/亩 | 数值 |

### 结果辅助字段（人工复核参考）

作物识别输出除交付的 9 列外，还附带以下质量字段，供后期人工判断识别结果是否可靠（口径源自工作记录 8.13「面向对象预测」）：

| 字段 | 含义 | 取值 |
|------|------|------|
| parcel_id | SLIC 分割地块编号 | 整数 |
| area_m2 | 地块面积（㎡） | 数值 |
| ndvi_max | 四期 NDVI 最大值（NDVI=(B08-B04)/(B08+B04)） | 0~1 |
| ndvi_flag | 植被标志（ndvi_max≥0.30 → 植被，否则非植被） | 植被 / 非植被 |
| predicted | 模型类别编码 | 0=水稻 / 1=玉米 |
| prdct_lbl | 模型类别名 | 水稻 / 玉米 |
| max_prob | 模型最大概率 | 0~1 |
| conf_flag | 置信度档位（≥0.70 高 / ≥0.60 中 / <0.60 低），非植被时标记"非植被" | 高 / 中 / 低 / 非植被 |
| prdct_cf | **最终判断结果** | 水稻 / 玉米 / 不确定 / 非植被(建筑/道路/裸土) |
| buf_pixel | 地块内有效 10m 像素数 | 整数 |
| px_statu | 像素状态 | OK / 过小(<3px) |

**最终结果 `prdct_cf` 由三条阈值链联合判定**：

```
buf_pixel < 1    → 无覆盖（地块未落在影像上）
ndvi_max < 0.30  → 非植被(建筑/道路/裸土)
max_prob < 0.60  → 不确定（模型不自信）
否则             → prdct_lbl（水稻 / 玉米）
```

> 人工复核要点：看作物 → `prdct_cf`；看可信度 → `conf_flag` + `max_prob`；看被排除原因 → `ndvi_flag` / `buf_pixel` / `px_statu`。三个阈值：NDVI=0.30、CONF_LOW=0.60、CONF_HIGH=0.70。
