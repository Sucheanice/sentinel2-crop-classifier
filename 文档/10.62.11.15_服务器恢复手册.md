## 三、Xinference 模型推理服务

### 3.1 启动服务

Xinference 使用 conda 环境 `xin`，需要后台运行:

```bash
source /root/anaconda3/etc/profile.d/conda.sh && conda activate xin && nohup xinference-local --host 0.0.0.0 --port 9997 > /tmp/xinference.log 2>&1 &
```

注意: `nohup ... &` 中的 `&` 在 SSH 中可能需要转义，推荐先 source conda 然后执行:

```bash
nohup /root/anaconda3/envs/xin/bin/xinference-local --host 0.0.0.0 --port 9997 > /tmp/xinference.log 2>&1 &
```

### 3.2 验证服务启动

```bash
# 等待约 10 秒后检查端口
ss -tlnp | grep 9997
```

应该看到: `LISTEN 0.0.0.0:9997`

### 3.3 启动模型

务必先确认 Xinference 服务已就绪 (端口 9997 可访问), 再启动模型:

```bash
source /root/anaconda3/etc/profile.d/conda.sh && conda activate xin

# bge-m3 嵌入模型 (GPU 0, 轻量)
xinference launch --model-name bge-m3 --model-type embedding

# Qwen3-32B AWQ Int4 (GPU 1, 大模型, 需约 18GB 显存)
xinference launch \
  --model-name Qwen3-32B \
  --model-type LLM \
  --model-format awq \
  --size-in-billions 32 \
  --quantization Int4 \
  --model-engine vllm \
  --gpu-idx 1 \
  --max-model-len 4096
```

### 3.4 查看模型状态

```bash
source /root/anaconda3/etc/profile.d/conda.sh && conda activate xin
xinference list
```

### 3.5 查看 GPU 显存

```bash
nvidia-smi
```

## 七、常见问题排查

### Q: mw-nginx 容器重启循环

```
症状: mw-nginx 或 mw-nginx-v2 反复 Exited → Restarting
原因: nginx.conf 中的 DNS 解析失败
修复: docker compose -f docker-compose.server.yml up -d --force-recreate nginx
      或 cd /data4/cezhihui30 && docker compose up -d --force-recreate
```

### Q: Qwen3-32B 启动报 "max seq len > max tokens in KV cache"

```
原因: GPU 显存不足支撑默认上下文长度
修复: 加参数 --max-model-len 4096 --gpu-idx 1
```

### Q: /data4/mappingwisdom_v2 用哪个 compose 文件?

```
错误: docker compose up -d  (会用 docker-compose.yml, 尝试启动 mw-mysql, 端口冲突)
正确: docker compose -f docker-compose.server.yml up -d
```

### Q: 宿主机 MySQL 连不上

```
# 检查 MySQL 是否运行
systemctl status mysql

# Docker 内后端通过 host.docker.internal:3306 连接
# root@localhost 使用 auth_socket 插件, 仅宿主机本地可用
# root@% 使用 mysql_native_password, Docker 内可用
```

### Q: XInference 端口 9997 无响应

```
# 检查进程
ps aux | grep xinference

# 重启动
kill $(pgrep -f xinference) 2>/dev/null
source /root/anaconda3/etc/profile.d/conda.sh && conda activate xin
nohup xinference-local --host 0.0.0.0 --port 9997 > /tmp/xinference.log 2>&1 &
```
